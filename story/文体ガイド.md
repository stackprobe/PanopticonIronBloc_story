# 文体ガイド

## 基本方針

本文は、ライトノベル的に一文ごと・一語ごとに改行して余韻を作る文体ではなく、段落の流れで読ませる小説文を基本とする。

ただし、すべてを長い段落へ詰め込む必要はない。硬く読みづらい文章にならないよう、場面の呼吸、視線の移動、会話の間に合わせて適度に段落を分ける。

内容の緊張感や沈黙は、改行の多さではなく、描写、語順、間、内面の積み重ねによって表現する。

## 改行の扱い

- 地の文は、意味のまとまりごとに段落化する。
- 単語や短い文を一行ずつ独立させすぎない。
- 長すぎる一段落にまとめすぎない。
- 箇条的な列挙を避けつつ、列挙の圧迫感や反復を見せたい場合は、中くらいの段落にまとめる。
- 重要な一文だけを独立させる場合は、場面の転換点や強い感情の変化など、明確な効果がある時に限る。

目安として、一段落には一つの視点・一つの動き・一つの心理のまとまりを置く。展示を見る、年表に気づく、記録を読む、沈黙する、といった変化があれば段落を分けてよい。

## 会話の扱い

会話文は独立行にしてよい。短い応答が連続して軽く見える場合だけ、必要に応じて地の文へ溶け込ませる。

台詞の末尾では、閉じ鍵括弧の直前に句点を置かない。句点付きの形ではなく、「あいうえお」とする。

例：

```markdown
「何がですか」と問われて、マリューシャは「ベルザニア軍のこと」と答え、前を向いたまま続けた。
```

短い台詞を何行も並べると、テンポが軽く見えやすい。ただし、会話まで無理に一段落へ押し込むと、今度は硬く読みづらくなる。

特に重い場面では、会話の前後に視線、沈黙、風景、身体感覚を置く。台詞そのものは独立させ、周囲の地の文で重さを支えるくらいがよい。

## 描写の方針

- 心情を直接説明しすぎず、風景や行動を通して滲ませる。
- ただし、分かりにくくなるほど省略しない。
- ベルザニアとアヴローラの差は、説明ではなく、同じ物事が二つの場所でどう違って見えるかで示す。
- マリューシャの警戒心は、言葉よりも視線、確認、沈黙、身体の反応に出す。

## 避けたい形

以下のような短行の連続は、必要な場面以外では避ける。

```markdown
宣戦布告。

国境紛争。

軍事衝突。

停戦提案。

拒否。
```

この場合は、次のように段落へまとめる。

```markdown
マリューシャはしばらく文字を追った。宣戦布告、国境紛争、軍事衝突。停戦提案、拒否。停戦提案、拒否。食糧支援協定、拒否。何度も、何度も同じ言葉が続いていた。
```

ただし、次のように一段落へ詰め込みすぎると硬くなる。

```markdown
マリューシャはしばらく文字を追った。宣戦布告、国境紛争、軍事衝突。停戦提案、拒否。停戦提案、拒否。食糧支援協定、拒否。共同復興計画、拒否。国境自由化提案、拒否。何度も、何度も同じ言葉が続いていた。まるで壊れた機械が、同じ応答だけを返し続けているようだった。マリューシャは年表から目を離せなくなった。
```

この場合は、次のくらいにほぐす。

```markdown
マリューシャはしばらく文字を追った。宣戦布告、国境紛争、軍事衝突。停戦提案、拒否。停戦提案、拒否。食糧支援協定、拒否。共同復興計画、拒否。国境自由化提案、拒否。

何度も、何度も同じ言葉が続いていた。まるで壊れた機械が、同じ応答だけを返し続けているようだった。
```

## 目指す読後感

文章は静かで重く、感情を煽りすぎない。読者に強い感情を指示するのではなく、登場人物の見ているもの、思い出してしまうもの、言葉にできず残るものを積み重ねる。

特にマリューシャの場面では、劇的な叫びよりも、理解してしまった後の沈黙や、納得できないまま残る問いを大切にする。
