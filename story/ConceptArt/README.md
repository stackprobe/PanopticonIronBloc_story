# Concept Art

このディレクトリは、各パートのコンセプトアート画像と、その生成に使用した描画プロンプトを管理する場所です。

## 注意

Codexに各パートを読んでもらい、画像を描いてもらった。そのためストーリーの内容と異なるところがある。

## ファイル構成

- `Picture_Part-XX.png`
  - 各パートのコンセプトアート画像。
- `DrawPrompt_Part-XX.txt`
  - 対応するコンセプトアート画像の描画プロンプト。
- [Gallery.md](./Gallery.md)
  - 各パートのコンセプトアート画像を元サイズで閲覧するためのギャラリー。
- [Characters](./Characters/)
  - 主要キャラクターのデザイン画像と描画プロンプト。

## 更新方針

- 新しいパートを追加する場合は、画像を `Picture_Part-XX.png`、描画プロンプトを `DrawPrompt_Part-XX.txt` の形式で追加する。
- 画像と描画プロンプトは同じパート番号で対応させる。
- キャラクター単体のデザイン資料は [Characters](./Characters/) に追加する。
