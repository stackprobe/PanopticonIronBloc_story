# Story Directory

このディレクトリは、ゲーム本編で使用する世界観設定、キャラクター設定、プロット本文を管理する場所です。

物語は、内戦と貧困に苦しむベルザニアから逃れてきたマリューシャとスネジャーナが、AIによって高度に管理された理想社会「アヴローラ連邦」へ辿り着き、平和な社会に適応していく過程を描きます。

## 執筆メモ

- マリューシャは、善意や理想郷を簡単には信じない。
- スネジャーナは、マリューシャより早くアヴローラの平和に心を開き始める。
- アヴローラの豊かさは、説明よりも「ベルザニアとの差」で見せる。
- イリーナは穏やかで善良だが、アヴローラでは当然のことを説明し忘れることがある。
- 物語の中心テーマは、「戦争しか知らない少女が、平和の中でどう生きるのか」。
